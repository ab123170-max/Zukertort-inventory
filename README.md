# Zukertort Inventory

Monorepo scaffold for an AI-powered inventory management app.

This repository contains:

- frontend/: Expo React Native app (cross-platform mobile + web)
- backend/: Node + Express backend using Prisma + SQLite
- weather-dashboard/: a static weather dashboard demo (Open-Meteo + Nominatim)

See frontend/README and backend/README for setup details.
